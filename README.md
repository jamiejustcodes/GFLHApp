# Greenfield Local Hub (GFLHApp)

An ASP.NET Core 9.0 MVC co-operative e-commerce web application connecting local producers and conscious consumers.

## Architecture
- **Framework**: ASP.NET Core 9.0 MVC
- **Database**: Entity Framework Core with SQLite / SQL Server
- **Authentication**: ASP.NET Core Identity with Role-Based Access Control (Admin, Producer, Standard, Developer) and Google OAuth
- **Frontend**: Responsive CSS design system with custom brand palette, animations, and accessibility features
